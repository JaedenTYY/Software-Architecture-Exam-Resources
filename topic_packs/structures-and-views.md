## Q02689 — Module vs C&C vs Allocation (Hard, 5 marks)

**Type:** Choose view  
**Exam family:** Extended  
**Scenario:** University Student Portal  

For the University Student Portal, choose the most appropriate architectural structure for each request: (a) show implementation responsibilities and dependencies, (b) show runtime communication during 'register for a subject', (c) show where software runs on devices/servers. Explain why each of the other two structures answers a different question.

<details><summary>Answer framework / marking outline</summary>

(a) **Module structure** - static organization of implementation units/responsibilities. (b) **Component-and-Connector** - runtime components and interaction mechanisms. (c) **Allocation** - mapping software to environment such as hardware, files or teams. One system can have all three; they are complementary views.



**Grounding:** Lecture1_What is Software ArchitectureV2.pdf; Lecture10_Documenting Software Architectures (1).pdf

</details>
