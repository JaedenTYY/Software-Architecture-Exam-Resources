## Suggested exam use

1. Use the papers to recognize the examiner's recurring question grammar.
2. Search the main exam engine using the key requirement or clue rather than memorizing one paper's answer.
3. Cross-check the predicted concept against `universal_answers.md` and the matching past-paper wording.
4. Pay attention to the distinction between architectural patterns, quality attributes, structures/views and implementation-level GoF design patterns.

The papers are intentionally kept separate from generated practice questions so that original past-paper wording remains easy to identify.
